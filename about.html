About KYVOREX SOUNDS

KYVOREX SOUNDS is an original sound library for game and application developers. Every sound is synthesized by our own audio engine — no third-party samples, no downloaded loops.

Version 1.0

The first release ships with a catalog of 10 sounds, each available as MP3 and WAV. The browser Preview plays the same sounds procedurally, so you can hear a sound without downloading it first.

Preview in your browser

Clicking Preview runs the procedural engine in your browser using the Web Audio API. No file is fetched, and no plugin is required.

Download in MP3 or WAV

  • MP3 for lightweight integration into games and apps.
  • WAV (mono, 44100 Hz, PCM 16-bit) for production.

Growing progressively

The catalog will expand over time. New sounds, categories and packs will be added while keeping the same clear structure and license.
